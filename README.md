# Diario Personal

## Descripción
Diario Personal es una aplicación web que permite escribir, guardar y consultar entradas personales. También cuenta con una función de análisis de emociones mediante inteligencia artificial.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Node.js
- Express
- Gemini API
- LocalStorage
- ##posible error de servidor
- 503 significa que los servidores de Google están temporalmente sobrecargados
